# LP Twin v1 — Founding Engagement Package

**Version:** 1.0.0
**Status:** READY FOR USE
**Last Updated:** 2026-08-07

> This document defines the founding customer engagement structure, success metrics,
> and the path from founding validation to commercial deployment.

---

## Engagement Overview

| Parameter | Value |
|---|---|
| **Engagement type** | Founding validation customer |
| **Duration** | 90 days |
| **Pricing** | Complimentary for founding customers |
| **Commitment** | Structured feedback + optional validation data contribution |
| **Deliverable** | Founding Customer Validation Report |

---

## Engagement Timeline

### Week 1–2: Onboarding
- Account provisioning and org setup
- Fund profile creation (8-step wizard)
- First simulation run (all 9 segments)
- Onboarding call (60 minutes)

### Week 3–4: Active Use
- Fund-Term Laboratory: 2–3 scenario tests
- Meeting preparation for top 3 target LP segments
- First real LP meeting (if applicable)
- Feedback session 1 (30 minutes)

### Month 2: Validation
- Record actual meeting outcomes in LP Twin
- Compare synthetic predictions vs actual responses
- Identify calibration opportunities
- Feedback session 2 (45 minutes)

### Month 3: Synthesis
- Full fundraising pipeline review
- Validation report preparation
- Commercial terms discussion
- Founding customer testimonial (optional)

## Success Metrics

The engagement is considered successful when:

| Metric | Target |
|---|---|
| Fund profiles created | ≥ 1 |
| Simulations run | ≥ 3 |
| Segments analysed | ≥ 9 (all segments) |
| Meeting briefs generated | ≥ 3 |
| Actual meetings recorded | ≥ 3 |
| Structured feedback sessions | ≥ 2 |
| Net Promoter Score | ≥ 7/10 |
| Accuracy rating (synthetic vs actual) | Collected (no target — first data) |

## Founding Customer Benefits

1. **Free access** to LP Twin v1 for 90 days
2. **Direct influence** on product roadmap through structured feedback
3. **Founding customer designation** on the AgenThinkMesh platform
4. **Priority access** to LP Twin v2 features (calibrated archetypes, real-data validation)
5. **Reduced commercial pricing** for the first 12 months post-launch
6. **Co-authorship** of the founding validation report (optional)

---

## Founding Customer Obligations

1. Complete the onboarding process within 2 weeks of account creation
2. Run at least 3 simulations during the engagement period
3. Attend at least 2 structured feedback sessions
4. Provide written feedback on the accuracy of synthetic LP outputs
5. Optionally contribute anonymised actual LP response data

---

## Validation Data Contribution

Founding customers are invited (but not required) to contribute anonymised actual LP
response data to the validation foundation. This data will be used to calibrate the
synthetic LP archetypes and improve the accuracy of future simulations.

**Data contribution is governed by:**
- Explicit participant consent (captured in the validation dashboard)
- Anonymization preferences set by the participant
- Permitted use restrictions (internal research, model improvement, etc.)
- The right to revoke consent at any time

**Data contributed will never be:**
- Attributed to a specific LP or individual without explicit consent
- Shared with third parties
- Used to make investment decisions
- Published without anonymization

---

## Path to Commercial Deployment

Following the founding validation engagement, LP Twin v1 will be available commercially
under the following conditions:

1. At least 1 founding customer completes the full 90-day engagement
2. At least 3 actual LP meetings are recorded and compared against synthetic predictions
3. The validation quality score reaches "developing" (≥ 20% agreement rate)
4. No critical security issues remain open
5. The full LP Twin test suite continues to pass (222+ tests)

**Projected commercial launch:** Q4 2026
**Pricing model:** Per-org subscription (annual), tiered by fund count and simulation volume
